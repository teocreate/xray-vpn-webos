# Changelog

## 0.3.1

- Fix: the first-run check no longer reports "could not install Xray-core" when the root service is merely slow (the TV opens the app at boot, while the service is still starting): it retries quietly, and if the service never answers it says so instead.
- Fix: after coming back from another app the status is re-read at once; a stuck "busy" state can no longer block the buttons, and commands fail within ~12 s with a clear message when the root service is stuck, instead of hanging for minutes.
- Fix: commands sent to the TV always return their output (the service used to drop it, and show the whole shell command as the error, when the exit code was non-zero).
- Fix: a running tunnel with no matching server (subscription deleted) is shown as "Tunnel is active" with its address; deleting the subscription of the connected server stops the tunnel. When the last server is deleted, the tunnel is stopped and `config.json`, the log and the cached ping results are removed, so autostart cannot bring back a deleted server.
- Fix: adding a subscription that cannot be downloaded shows a persistent error with the reason and a Retry button; a failed download can no longer reuse a previously downloaded subscription.

- Subscription info: days left (green, yellow within 7 days, red when expired) and traffic used / limit, read from the provider's `subscription-userinfo` header, are shown above the list.
- Ping and refresh are icon buttons (speedometer, circular arrows) that show their label when focused.
- Decorative emoji in server names are hidden.
- Setup: an empty or odd reply from the root service is retried and reported as a service problem, never as "could not install Xray-core".

## 0.3.0

- **Install without a PC.** On first launch the app installs `vpnctl` and `boot_hook.sh` (shipped inside the package under `tv/`) and downloads Xray-core from its official GitHub release with SHA-256 verification, so the Homebrew Channel package works on its own. `install.sh` still works.
- The package now includes the TV helper scripts; `scripts/stage.sh` assembles it.

## 0.2.1

- New app icon and launch screen (splash).
- Homebrew Channel repository: `repo.json` in the repo root and a `<id>.manifest.json` release asset generated by `release.sh`.

## 0.2.0

- New interface: two-column layout with a round power button, status and uptime, country-code badges, ping dots,
  QR code for add-from-phone, settings with toggles, error screen with retry.
- UI in Russian and English (follows the TV language). Bundled Onest and JetBrains Mono fonts.
- The add-from-phone page was redesigned, follows the phone language and serves its own fonts from the TV.
- Screenshots in the READMEs.
- A stale "Connecting…" message no longer stays over the error dialog.
- Root-command calls now time out (45 s) and show an error instead of hanging on "Please wait" when the
  Homebrew Channel service stops answering.
- Keep-alive ping every 10 s so that service does not idle out in the middle of connecting or pinging.

## 0.1.0

First public release.

- Full-device Xray `tun` tunnel for rooted webOS TVs, controlled from a Magic Remote friendly app.
- Subscriptions (base64, plain, Happ-style JSON), manual links, add-from-phone page on port 8088.
- VLESS (Reality/TLS; tcp, ws, grpc, xhttp, httpupgrade), VMess, Trojan, Shadowsocks, Hysteria2.
- `vpnctl` with watchdog (crash/interface-change recovery, fail-open), OOM protection, memory limit,
  `rp_filter` handling, autostart via webosbrew init.d.
- Installer (`scripts/install.sh`) that fetches and verifies Xray-core.
- Honest device identification for providers that limit devices.
